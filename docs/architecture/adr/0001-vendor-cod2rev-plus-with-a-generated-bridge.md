# 0001. Vendor CoD2rev-Plus behind a generated bridge

- Status: Accepted
- Date: 2026-10-18

## Context

The reconstructed server and script VM crashed as soon as a second player joined. CoD2rev-Plus is a C++ reconstruction of the same server that runs real games, but its names, signatures and some layouts differ from the engine's.

## Decision

Copy CoD2rev-Plus's script VM, server, game, bgame, core, xanim and libcod byte for byte (`test/vendored_files.txt`) and connect them to the engine through `src/compat`, generated by `scripts/gen_script_bridge.py` from interface lists, with each crossing asserted against the engine's ABI.

## Consequences

- The dedicated server runs only CoD2rev-Plus's code; upstream fixes apply with `git am`.
- Every new crossing needs an interface entry and an ABI check.
- Two copies of some code (engine and CoD2rev-Plus) coexist; `test/plus_replaces.txt` keeps one copy of each state per executable.
